# Tabloom Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Deliver a tested opt-in browser extension and agent tools in one private repository.
**Architecture:** Extension enforces grants; authenticated loopback bridge routes typed commands; CLI and MCP expose the same tools; skill documents the workflow.
**Tech Stack:** Node 22+ ESM, ws, MCP SDK, Chrome 125+ MV3, Node test runner, Playwright for real extension tests.
**Spec:** docs/superpowers/specs/2026-09-05-tabloom-design.md

## Global Constraints

- Name: Tabloom; private repository iamkunal9/tabloom. No assistant attribution or co-author trailers.
- Node 22+ ESM; Chrome 125+ MV3. Loopback port 17653 default.
- Off/current-tab/full-browser scope enforced in extension; HTTP(S) non-incognito only; no remote enable or arbitrary eval/CDP.
- Token authentication, origin and host checks, bounded input, timeouts, disconnect revocation. Tokens never enter repository.
- User authorized complete implementation, testing, installation needed for testing, and private GitHub publication; continue without intermediate approval gates.

### Task 1: Extension and authorization engine

**Files:** extension/manifest.json, extension/background.js, extension/scope.js, extension/actions.js, extension/popup.html, extension/popup.js, extension/popup.css, extension/icons/*, tests/scope.test.js, tests/actions.test.js, package.json.
**Interfaces:** consumes WS protocol in spec; produces runnable load-unpacked extension. Exports scope/action validation modules for Node tests. UI labels: Current tab, Full browser, Stop all control, Pair bridge; inputs Bridge port and Pairing token. Pairing persisted in storage.local; grant uses storage.session or volatile state with restart revocation. Current tab selection from chrome.tabs.query active tab in current window; test may open popup.html as an extension page, requiring target selection to remain the last normal active tab or explicit target test setup. Never add test-only production bypasses.

- [ ] Write failing tests that deny unapproved tab IDs, reject internal URLs/incognito, preserve captured current-tab ID, include future tabs for browser scope, revoke immediately, and reject unsupported actions/invalid arguments.
- [ ] Implement grant generation checking and serialized action execution, debugger attachment/detachment, snapshot/selectors, CDP click/type/key/scroll/screenshot/navigation, and browser-only open/close. Every awaited operation that precedes an effect rechecks grant generation; Stop clears grants synchronously.
- [ ] Build popup with paired/connected/scope status, masked pairing token, explicit browser scope description, clear errors, and visible badge. Reconnect alarms plus 20s heartbeat; reconnect must not restore grants.
- [ ] Run `node --test tests/scope.test.js tests/actions.test.js`, document evidence, commit only task files.

Store config in ~/.config/tabloom with owner-only file permissions. `client.command(method,params)` reads port/token from config. Installed helper should locate absolute CLI regardless of caller cwd.
